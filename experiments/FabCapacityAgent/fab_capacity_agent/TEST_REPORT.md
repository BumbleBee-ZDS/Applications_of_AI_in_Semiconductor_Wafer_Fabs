4. **[P2/离子注入/工艺]** 离子注入工序: 当前 OEE 高达 97.67%, 但利用率极低(16.72%), 说明机台产能远大于需求。建议重新评估产品路线, 将部分 IMP 工艺转移至利用率较低的机台, 或考虑将部分 IMP 产能外包/共享。
