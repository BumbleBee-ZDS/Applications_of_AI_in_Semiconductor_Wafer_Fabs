# 第12章 成熟量產期——穩定營運中的效率與韌性

## 12.1 階段定位：量產穩定後的核心矛盾

當良率爬升到目標水準、產能達到設計值，晶圓廠進入成熟量產期。這個階段業務環境的特點是「穩定中的競爭」：良率和產能不再是主要矛盾（牠們是「入場券」），**成本、效率和品質一致性**成為核心：

- **成本**：產能利用率每提升1%、設備OEE每提升1個百分點，都意味著數千萬美元級的年度收益
- **效率**：在同樣的設備投入下，循環時間（Cycle Time）更短、產出更多，就是競爭力
- **韌性**：設備老化、市場波動、突發擾動（急單、設備故障）下的穩定營運能力

成熟期沒有建設期那種「從0到1」的戲劇性，但每一步最佳化都是真金白銀。本章聚焦成熟期三個核心任務：智慧排程、預測性維護、能源管理。

## 12.2 任務一：智慧排程（Smart Scheduling）

### 成熟期的排程挑戰

成熟量產期的典型特徵是**多品種混合生產**：同一產線上並行流片多種產品（不同製程、不同交期、不同優先級），傳統靜態派工規則（FIFO、按交期優先）在複雜場景下效果明顯下降。疊加動態擾動（設備故障、急單插單、瓶頸漂移），排程成為一個高頻次的動態決策問題：

- 下一批晶圓派到哪台設備？
- 瓶頸設備前排隊的一堆批次，先做哪一個？
- 設備故障時，哪些批次需要重新路由？

### 排程最佳化目標

智慧排程需要同時最佳化多個互相衝突的目標：

| 目標 | 含義 |
| --- | --- |
| 縮短循環時間 | 晶圓從投入到產出更快 |
| 提高瓶頸利用率 | 瓶頸設備不空閒 |
| 滿足交期 | 客戶訂單按時交付 |
| 負載均衡 | 各機台工作量均衡，避免局部壅塞 |

### AI 的角色：從規則到強化學習

傳統排程依賴人工規則（專家經驗編碼），在穩定場景下有效，但在多品種、高擾動場景下力不從心。AI的介入分兩個層次：

- **預測層**：用機器學習預測WIP流動、瓶頸轉移和產出——「提前看到問題」，為調度決策提供前瞻資訊
- **決策層**：用強化學習（RL）訓練調度策略——將排程建模為馬可夫決策過程，策略網路直接輸出派工決策，在模擬環境中訓練後部署到產線（詳見第16章行為主義）

產業驗證方面，AISSI專案在真實工業數據集上驗證了深度強化學習調度（DQN、MARL）的效果，在模擬與產線驗證中實現了約9%的產出提升（詳見第16章）。

## 12.3 任務二：預測性維護（Predictive Maintenance）

### 成熟期的設備維護問題

設備進入成熟期後，部件老化導致故障率上升。傳統的維護策略是定期預防性維護（PM）和故障後修復（事後維護），兩者各有代價：**PM過頻浪費產能**（設備停機做維護就是產能損失），**PM不足則增加非計畫停機風險**——而非計畫停機的代價遠高於計畫停機：打亂排程、延誤交期、可能造成批次報廢。

### 預測性維護的任務鏈條

1. **狀態感知**：從設備FDC感測器數據（振動、溫度、電流、壓力）中提取健康特徵
2. **剩餘壽命預測（RUL）**：預測部件還能安全運行多久，輸出「建議PM時間窗口」
3. **故障預警**：檢測異常徵兆（參數漂移、訊號異常），提前告警
4. **維護決策最佳化**：結合生產排程決定「何時停機維護損失最小」

### AI 的角色

- **異常檢測**：利用時序模型（LSTM、Transformer等）檢測設備參數的異常漂移（詳見第15章連接主義）
- **RUL預測**：基於歷史故障數據和退化軌跡訓練壽命預測模型（詳見第8章預測性維護技術）
- **維護決策**：用最佳化演算法/RL將「維護時機」與「生產排程」聯合最佳化——在設備風險與產能損失之間取平衡

預測性維護的價值不僅是減少停機，更是將維護從「計畫內的固定節奏」變為「數據驅動的動態節奏」，這對成熟期「每一分鐘產能都很貴」的營運尤為關鍵。

## 12.4 任務三：能源管理（Energy Management）

### 晶圓廠的能耗問題

晶圓廠是典型的能耗大戶：一座先進晶圓廠的年電費以億級美元計，潔淨室（恆溫恆濕、超淨通風）、製程機台（高溫爐管、電漿設備）、輔助系統（冷卻、空壓、廢水處理）都是耗電主力。隨著全球碳減排趨勢（半導體產業佔全球碳排放約0.3%且持續增長）和電價上漲，能源管理從「後勤成本」上升為「戰略競爭力」。

### 能源管理的任務鏈條

1. **能耗監測**：建立設備級、區域級、工廠級的能耗基線（哪些設備耗電多少、何時達到峰值）
2. **能耗預測**：基於生產計畫預測未來能耗曲線，識別峰谷
3. **動態最佳化**：在滿足生產約束的前提下最佳化用能——錯峰生產（高電價時段降低非關鍵負載）、機台待機策略（空閒機台進入低功耗待機）、潔淨室空調系統動態調校（根據生產負荷調節新風量）
4. **能效評估**：將能耗納入設備選型、製程評估和營運考核

### AI 的角色

- **能耗預測**：用時序模型預測能耗，為錯峰和調度提供依據
- **最佳化調度**：將「能耗成本」納入排程目標函數——同樣一批活，安排在低電價時段做，成本更低（與12.2智慧排程聯動）
- **異常能耗檢測**：識別設備能耗異常（如某腔體耗電突增，可能預示故障）

能源管理是成熟期AI應用中被低估的方向：牠不需要改變製程，就能帶來直接的、可量化的成本節省，且與綠色製造（ESG）趨勢契合。

## 12.5 成熟期的 AI 落地要點

成熟期AI落地的核心是**ROI導向**——每個專案都要對應明確的成本/效率指標：

1. **從高確定性專案起步**：預測性維護（非計畫停機減少）、虛擬量測（量測產能釋放）等專案收益可量化、見效快，適合作為成熟期AI的首批專案
2. **深度整合生產系統**：成熟期的AI不是獨立工具，必須與MES、APC（先進製程控制）、FDC等生產系統深度整合——AI的輸出直接進入生產決策鏈路
3. **持續疊代機制**：成熟期數據充足，AI模型可以持續疊代最佳化，需要建立「模型訓練-評估-上線-回饋」的營運機制

## 12.6 本章小結

成熟量產期是晶圓廠「收穫」的階段，核心矛盾從「做出來」轉向「做得省、做得快、做得穩」。智慧排程解決「資源怎麼分配」，預測性維護解決「設備別掉鏈子」，能源管理解決「每一度電都花得值」。三者的共同特點是：AI的輸出直接轉化為可量化的成本與效率收益。對成熟期晶圓廠而言，AI不是錦上添花，而是維持成本競爭力的必備能力——當競爭對手透過智慧排程多產出9%、透過預測性維護減少20%非計畫停機時，不採用AI的工廠將處於結構性劣勢。
