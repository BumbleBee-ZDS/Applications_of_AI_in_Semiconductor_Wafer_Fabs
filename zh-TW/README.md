> 從1956年達特茅斯會議到Palantir幫三星提升良率——一本系統梳理人工智慧在半導體製造中落地實踐的開源技術書。

半導體製造是人類工業皇冠上最精密的明珠，一座先進製程晶圓廠的造價超過150億美元，一片晶圓上承載著數千億顆電晶體。在這個良率每提升1%就意味著數千萬美元利潤的產業裡，AI正在從實驗室走向產線，從論文走向車間。

本書以**晶圓廠三大核心部門**為業務主線，以**AI三大流派**為技術主線，雙線交織，系統講解AI技術如何真正在半導體晶圓廠中落地。

## 適合誰讀

- **半導體工程師**——想了解AI如何在自己所在的製程、良率、製造、設備領域落地
- **AI演算法工程師**——想理解半導體製造場景的特殊性，找到有價值的工業AI應用方向
- **Fab管理層與IT負責人**——想知道哪些AI技術值得投資，哪些還在概念驗證階段
- **高校研究生與研究者**——需要一本將AI理論與半導體實踐結合的參考書
- **技術投資人**——想看懂半導體AI賽道的底層邏輯
